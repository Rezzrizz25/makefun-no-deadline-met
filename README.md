A single-line excuse for a missed deadline, written the way someone would actually say it out loud — no setup, no second line, just the excuse.

> My calendar said the deadline was Friday, my brain heard 'eventually,' and here we are.

## Run it

```sh
node main.ts
```

This writes the entry line to `entry.txt` inside `$MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
